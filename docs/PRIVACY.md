# 保存与导出范围

主仓库必须保持私有，因为它同时保存职业、产品、个人目标和限制级财务历史。不要用公开GitHub仓库、GitHub Pages或公开附件承载整套主档案。

| 标签 | 适用内容 | 默认导出 |
| --- | --- | --- |
| public | 本人明确批准公开的内容 | 仍要求public_approved=true |
| private | 个人偏好、产品内部背景、工作方式、计划 | 可信日常产品所需范围 |
| restricted | 收入储蓄、未确认姓名线索、特定内部目标 | 仅显式restricted导出 |

标签不构成仓库内部隔离。仓库协作者与有完整读取权限的应用能够看到已提交的全部内容。若未来需要真正隔离，拆成不同私有仓库或将限制级内容移至独立受控存储；不要假装 `.gitignore` 能移除已提交数据。

公开导出移除来源ID与来源注册表，不携带Library定位。普通导出保留来源ID用于内部追溯，来源原文和定位仍需主仓库权限。

禁止入库：密码、Token、登录态文件、SSH私钥、钱包私钥、证件号、客户原始资料和带访问凭据的URL。可以记录“已完成认证”的事实及其边界，不必复制认证材料。

导出不等于授权上传。应按当前任务授权和产品数据处理方式选择范围；不要因为某产品“需要了解我”就给它所有财务或内部计划。
